# Privacidade do CineMatch

O CineMatch guarda o perfil sincronizado do Letterboxd, preferências, filmes salvos e histórico de recomendações no armazenamento local da extensão, dentro do navegador do usuário.

Esses dados não são enviados para um servidor do CineMatch. Durante a sincronização, a extensão consulta páginas públicas do Letterboxd; quando há uma aba do Letterboxd aberta, ela pode usar a sessão já autenticada nessa aba para completar a consulta. Pôsteres podem ser baixados do domínio de imagens do TMDB.

O usuário pode apagar o perfil sincronizado a qualquer momento em **Configurações → Apagar perfil salvo**. Filmes salvos e histórico de buscas permanecem até serem removidos em uma versão futura da interface ou com a limpeza de dados da extensão pelo navegador.

O CineMatch não coleta credenciais, tokens, informações de pagamento ou dados de navegação fora do Letterboxd.
